AuthInject-RAG

Authorization-first RAG with indirect prompt-injection defenses, exposed as a chatbot you can embed on a website or drive from the CLI.

Embed on your site

Point visitors at this API, ingest documents as the widget user, then drop in:

<script
  src="https://YOUR_HOST/static/widget.js"
  data-api-url="https://YOUR_HOST"
  data-site-key="YOUR_SITE_KEY"
  defer></script>

CLI

secure-rag
secure-rag --once "What is dual control?"
secure-rag --api http://127.0.0.1:8080 --site-key YOUR_SITE_KEY

The launcher on this page talks to the same origin using your configured site key.
